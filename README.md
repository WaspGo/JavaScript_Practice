## Як користуватися

Відкрий потрібний Markdown-файл у режимі попереднього перегляду редактора. Для пошуку використовуй назву теми, задачі або функції: `forEach`, `Object.assign`, `createCounter`, `factorial`. Приклади з `prompt` потребують браузера.

Блоки містять початкові спроби розв’язків, а не перевірений довідник. Код збережено дослівно; тематичні файли призначені для читання та роботи з окремими прикладами.
