# Навчальна база фільмів

[До навігатора](../../README.md)

[Код](script.js) • [Сторінка запуску](../../index.html)

Відкрий `index.html` у корені Practice у браузері та консоль розробника. Скрипт запитує кількість переглянутих фільмів, два фільми з оцінками та три улюблені жанри.

Приклад охоплює об’єкти, методи, цикли, перевірки введення, `prompt` та `forEach`. Початковий код перенесено без змін.

Відомі особливості початкового розв’язку: скасування діалогу назви фільму призводить до помилки через виклик `.trim()` на `null`; кількість `0` повторно запитується через нестроге порівняння з порожнім рядком.
